## 🚨 Symptoms of the Wrong Dashboard Design

Before you drag another visual onto the canvas, check whether your report suffers from any of these classic symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 🐌 Sluggish visuals | Bad data model | Star schema + relationships |
| 🔢 Wrong totals | Missing filter context | Correct DAX measures |
| 🕳️ Blank KPIs | Text columns as dates | Data type fixes |
| 🧊 Static reports | No interactions | Slicer + cross-filter |
| 🔀 Duplicated pages | No parameters | Bookmarks + field params |
| 📉 Executives ignore it | Too many charts | Focused KPI layout |

> **💡 Tip:** If any visual takes more than 2 seconds to load, your relationships are almost certainly wrong.

## 🚀 First 5 Minutes — Minimal Working Example

This is the smallest dashboard you can ship.

**Step 1 — Load data.** Import an Excel or CSV of orders.

**Step 2 — Create a date table.** Use CALENDARAUTO().

**Step 3 — Build a KPI card.** Sum of Total Orders.

**Step 4 — Add a bar chart.** Orders by month.

**Step 5 — Add a slicer.** By Region.

> **💡 Tip:** Always start with the total KPI card — it anchors the whole dashboard.

| **Filters** | Slicers + sync | Unlinked pages |
